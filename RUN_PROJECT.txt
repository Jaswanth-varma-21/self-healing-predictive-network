RUNNING THE DEMO

1. Extract this ZIP.
2. Open Ubuntu/WSL.
3. Activate the Python environment (if you use it):
   source /home/jashu/ryu-env/bin/activate
4. Enter the extracted project directory. Example:
   cd /mnt/c/Users/HP/OneDrive/Desktop/cn_project_fixed/cn_project
   Adjust this path if you extracted somewhere else.
5. Start the dashboard:
   python3 demo/live_demo.py
6. Open in your browser:
   http://127.0.0.1:8765

Keep the terminal open while using the dashboard. Stop it with Ctrl+C.
